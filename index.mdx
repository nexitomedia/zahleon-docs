## Verfügbarkeit

Die dokumentierte Application API befindet sich in einer privaten
Entwickler-Preview. Sie verwendet derzeit die Zahleon-Browsersitzung und
ist nicht als allgemeine Public API mit persönlichen API-Schlüsseln
freigegeben.
